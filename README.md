# HWOS — Hacker Web OS

**Сделано в Санкт-Петербурге ❤️**

HWOS — это российская операционная система на базе Arch Linux. Простая, понятная и безопасная.
Создана для тех, кто хочет получить полный контроль над своей системой без сложностей.

## Возможности

- **Hacker Shell** — собственная оболочка с автодополнением, русским интерфейсом и умным промптом
- **hwins** — собственный менеджер пакетов (обёртка над pacman) на русском языке
- **Hacker-Kernel (linux-hacker)** — кастомное ядро на базе Linux 6.1 LTS с патчами безопасности
- **HackerRUB** — фирменный загрузчик GRUB с темой в цветах российского флага
- **TUI-инсталер** — установка в несколько кликов, режимы «Для новичков» и «Эксперт»
- **Два региона** — переключение между 🇷🇺 Россия (Яндекс-зеркала) и 🌍 Международный
- **Только WM** — Hyprland, i3, sway. Никаких DE
- **Безопасность** — встроенный фаервол (nftables), шифрование (LUKS), закалённое ядро
- **Русский язык** — всё от установки до подсказок на русском

## Быстрый старт

### Установка с ISO

1. Загрузитесь с HWOS ISO
2. В меню GRUB выберите «Запустить HWOS» или «Установить HWOS на диск»
3. В TUI-инсталере выберите регион, язык, режим, диск и пользователя
4. Дождитесь окончания установки и перезагрузитесь

### Основные команды

| Команда | Описание |
|---------|----------|
| `hwins install пакет` | Установить программу |
| `hwins remove пакет` | Удалить программу |
| `hwins search запрос` | Найти программу |
| `hwins update` | Обновить базу пакетов |
| `hwins upgrade` | Обновить все программы |
| `hwos-update all` | Полное обновление системы |
| `hwos-firewall enable` | Включить фаервол |
| `hwos-encrypt disk` | Зашифровать диск |
| `hwos-installer` | Запустить установщик |
| `hwos-region ru` | Переключить на 🇷🇺 регион |
| `hwos-region int` | Переключить на 🌍 регион |
| `hwfetch` | Информация о системе |
| `hwos-help` | Полная справка |
| `hacker` | Hacker Shell |

## Регионы

HWOS поддерживает два режима работы:

- **🇷🇺 Россия** — русский язык, раскладка ru, часовой пояс Москва, приоритет зеркала Яндекса
- **🌍 Международный** — английский язык, раскладка us, UTC, глобальные зеркала

Переключение: `sudo hwos-region ru` или `sudo hwos-region int`
