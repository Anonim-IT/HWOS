# Участие в разработке HWOS

HWOS — открытый проект. Мы рады любой помощи!

## Как помочь

### Сообщить об ошибке

Создайте Issue на GitHub: https://github.com/Anonim-IT/HWOS/issues

Опишите:
- Что произошло
- Ожидаемое поведение
- Как воспроизвести
- Версию HWOS

### Предложить улучшение

Создайте Issue с меткой `enhancement`.

### Отправить Pull Request

1. Форкните репозиторий
2. Создайте ветку: `git checkout -b feature/название`
3. Внесите изменения
4. Запустите проверку: `bash scripts/lint.sh`
5. Отправьте PR

## Стиль кода

### Bash
- `set -euo pipefail` в начале скриптов
- Переменные в `UPPER_CASE` для глобальных, `lower_case` для локальных
- Комментарии на русском (для пользовательских сообщений) и английском (для кода)

### Python
- PEP 8
- Типизация (type hints)
- Русские строки через `_()` для перевода

### PKGBUILD
- Следуйте стандартам Arch Linux
- Указывайте `maintainer`
- Используйте `SKIP` для checksum при разработке

## Структура пакета

```
packages/название/
├── PKGBUILD
├── название.install     # post-install (опционально)
└── src/                 # исходники (опционально)
```

## Тестирование

Перед отправкой PR убедитесь, что:

1. Пакет собирается: `makepkg -s` в директории пакета
2. ISO собирается: `sudo ./scripts/build-iso.sh`
3. Установка проходит: TUI-инсталер отрабатывает без ошибок
