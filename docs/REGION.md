# Переключение региона

HWOS поддерживает два региона. Всё — от зеркал до раскладки — переключается одной командой.

## Команды

```bash
hwos-region status    # Показать текущий регион
hwos-region ru        # 🇷🇺 Россия
hwos-region int       # 🌍 Международный
```

## Что меняется

| Параметр | 🇷🇺 Россия | 🌍 Международный |
|----------|-----------|-----------------|
| Язык | `ru_RU.UTF-8` | `en_US.UTF-8` |
| Раскладка | `ru` (cyr-sun16) | `us` |
| Часовой пояс | `Europe/Moscow` | `UTC` |
| Зеркала | Яндекс (приоритет) | Colo-Serv, Rackspace, Kernel.org |
| Регион в os-release | `ru` | `int` |

## Примеры

```bash
# Посмотреть текущий регион
hwos-region status

# Переключиться на Россию
sudo hwos-region ru

# Переключиться на международный
sudo hwos-region int
```
